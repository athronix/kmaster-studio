## 二、产品定义

### 2.1 产品目标

1. **统一交互范型**：将所有资源市场页（专家/技能/MCP）收敛为一致的浏览-安装-召唤体验，消除用户在不同页面间的认知切换成本。
2. **重构会话体验**：将会话交互页从当前碎片化状态重构为信息密度合理、操作路径清晰的主工作区，一次会话内即可完成 Agent 切换、文件上传、技能挂载、模型选择等全部配置。
3. **消灭已知缺陷**：修复左栏会话导航、市场页展示异常、刷新丢状态等 6 个线上 Bug，确保基础可用性。

### 2.2 用户故事

| # | 用户故事 | 对应需求 |
|---|---------|---------|
| US1 | 作为用户，我点击左栏任意会话项，无论当前主体栏在什么页面，都能直接打开该会话交互页 | 一-1 |
| US2 | 作为用户，我在专家/技能/MCP 市场浏览时，能一键召唤资源创建新会话，或一键卸载已安装资源，且已安装的资源有明确视觉标识 | 一-2/3/4 |
| US3 | 作为用户，新建会话时系统自动填入合理的默认配置，我无需每次都手动设置 | 三 |
| US4 | 作为用户，在会话交互页我可以随时切换 Agent、模型、权限模式、挂载技能/MCP，无需离开当前会话 | 四 |
| US5 | 作为用户，设置/管理页（Agent/技能/MCP/Plugins）拥有一致的浏览和操作方式，我学会一个就会用全部 | 五 |

| **P0-13** | **Agent 角色标签栏** | 多 Agent 会话平铺标签，点击切换显示对应 Agent 对话。单 Agent 一个标签。专家团显示所有参与 Agent 标签。 |
