## 0. 使用说明

- **适用对象**：QA 人工走查；主理人向用户汇报「做到了没有」的凭据。
- **条目格式**：`[AC-XX] [优先级] [维度] 操作 → 预期可观察结果`。
- **维度标签**：
  - `默认态` — 首次 / 冷启动应呈现的布局；
  - `持久化` — 用户操作 / 偏好在刷新后保持；
  - `互斥性` — 分组非互斥、新行为覆盖旧行为；
  - `功能` — 单次交互的可见结果。
- **双向验证（关键）**：凡标 `默认态 / 持久化 / 互斥性` 的项，**必须同时验 ✅ 新行为生效 与 ❌ 旧行为消失**。只验前者，PRD §7.7 的 6 条静默冲突会全部漏过（见 §3 索引）。
- **追踪标注**：每条尾注 `[原话N]`（用户原始需求句）+ `[PRD F-xx/B-xx]`（内部需求 ID）。
- **计数与缩写**：`会话(N)`、`定时任务(N)` 的 `N` 为**未归档**总会话数 / 总任务数（归档为软隐藏，不计入）；`running` = 会话 / 任务正在运行。
- **优先级**：P0 阻塞交付 / P1 应修 / P2 可延后。

## 2. 剧本正文

### 原话① — 首页默认态

**[AC-01][P0][默认态] 冷启动（localStorage 为空，无用户折叠偏好）**
→ 左栏「会话 (N)」父节点**展开**（F-01 程序化展开一次）；其下 **Recent 展开、置顶 展开、全部工作目录 收缩**；**Recent 首条被选中并高亮**；主体栏渲染该会话历史消息与可输入输入框；**右栏关闭**。
- ✅ 新行为：上述布局成立。
- ❌ 旧行为消失：右栏自动打开（旧可能存在）；工作目录组默认全展开（旧 `LeftSidebar.vue:98` `defaultExpanded = Object.keys(byWorkspace)`）。

**[AC-02][P0][默认态] 无任何会话时冷启动**
→ 主体栏呈现空态文案「暂无会话，点击「新建任务」开始」+ 新建任务引导；无报错、无空白崩溃区。

**[AC-03][P0][默认态] 右栏默认不打开（全场景）**
→ 冷启动后、以及任意路由下，右栏均为 `hidden` 态；不因选中会话 / 切到主页而自动弹出。

### 原话② — 新建任务不常亮

**[AC-04][P0][默认态] 在任意路由下观察「新建任务」按钮**
→ 在首页 / 专家页 / 技能页 / MCP 页 / 定时任务详情页等，**「新建任务」外观与未激活菜单项完全一致**（无底色、无高亮、无 selected 态残留）。[PRD F-02]

**[AC-05][P1][功能] 点击「新建任务」**
→ 弹出 `NewTaskDialog`（7 项配置表单）；填写确认 → 自动 `openSession` 新会话，**Recent 分组首位即时出现该会话**，主体栏打开该会话，无需二次点击。[PRD F-12]

### 原话③ — 左栏菜单行为

**[AC-06][P0][功能] 观察专家 / 技能 / MCP 三项菜单**
→ 三项右侧均显示 `已安装/总数` 徽标（如 `12/86`）。[PRD F-03]

**[AC-07][P0][默认态 / 互斥性] 校验计数口径**
→ 计数 = 已安装 ∪ 候选 **按唯一 key 去重**后计数；**已安装 ≤ 总数 恒成立**；禁止 installed 与 total 直接相加导致 `installed > total` 的荒诞值；数据未就绪显示 `—/—` 骨架，不显示 `0/0`。[PRD F-03 / §7-Q1]
- ✅ 新行为：已安装 ≤ 总数、且与对应卡片页实际卡片数一致。
- ❌ 旧行为消失：任何「求和」口径若曾存在则不再出现。

**[AC-08][P0][功能] 点击专家 / 技能 / MCP**
→ 主体栏分别打开 `/experts`、`/skills`、`/mcp` **卡片 list 页**（卡片网格，非表格）；当前路由项高亮，其余不高亮。[PRD F-03 / F-11 / US-2]

**[AC-09][P0][功能] 点击「新建任务」**
→ 弹出 `NewTaskDialog` 弹窗（非路由跳转），确认逻辑见 AC-05。[PRD F-12 / Q6]

### 原话④-1 — 会话 (总数) 可折叠父节点

**[AC-10][P0][默认态] 会话 (N) 父节点**
→ 可点击展开 / 收缩；标题显示总数 `N`（= 未归档总会话数）。其**持久化默认 = 收缩**，但冷启动首页由 F-01 程序化展开一次（见 AC-01 / AC-16）。[PRD F-04]

**[AC-11][P0][持久化] 手动折叠 / 展开会话 (N) 父节点**
→ 手动收缩 → 刷新页面仍收缩；手动展开 → 刷新仍展开（localStorage 持久化）。
- ✅ 新行为：折叠状态跨刷新保持。
- ❌ 旧行为消失：无持久化或「永远展开」。

### 原话④-2 — 三类分组 + 组内倒序 + 工作目录按名称

**[AC-12][P0][默认态] 展开会话区后**
→ 呈现三类分组：**Recent (n) / 置顶 (n) / 各工作目录 (n)**，每组标题带数量徽标。[PRD F-05 / F-14]

**[AC-13][P0][默认态] 分组默认展开态**
→ **Recent 默认展开；置顶 默认展开；每个工作目录组默认收缩**。
- ✅ 新行为：工作目录组默认收缩。
- ❌ 旧行为消失：旧 `defaultExpanded = Object.keys(byWorkspace)` 使**全部工作目录默认展开** → 必须消失。[PRD §10.5-D / 静默冲突②]

**[AC-14][P0][默认态] 工作目录组排序**
→ 工作目录组之间按**目录名字典序升序**排列；「未绑定工作目录」组**恒置最末**（兜底层，不混入真实目录中间）。
- ✅ 新行为：按名称升序、未绑定置末。
- ❌ 旧行为消失：曾按「最新 updated_at 倒序」排组（架构师初版，已纠正 §10.3）→ 消失。[PRD §10.3]

**[AC-15][P0][默认态] 组内排序**
→ Recent / 置顶 / 各工作目录组内，会话均按 `updated_at` **严格倒序**。[PRD F-05]

**[AC-16][P0][默认态] 首次访问空 localStorage**
→ **必须落到「Recent 展开 / 置顶 展开 / 全部工作目录 收缩」**（F-05 验收点，主理人补充）。持久化读取逻辑不得把「空状态」误判为「全展开」。[PRD §10.5-D / F-05]

### 原话④-3 — Recent 规则

**[AC-17][P1][默认态] Recent 成员构成**
→ = **running 会话 ∪ (updated_at 倒序前 5) ∪ (3h 内更新)** 的并集；去重；**running 稳定居首**；硬上限 **20** 截断。[PRD F-05 / §7-Q2]

**[AC-18][P2][功能] Recent 阈值可配置**
→ 设置页暴露「Recent 条数上限」「时间窗口 (小时)」两项输入（F-20）。[PRD F-20]

### 原话④-4 — 会话行：名称 + 时间 / running 图标

**[AC-19][P0][默认态] 会话行基础显示**
→ 显示 **名称 + 相对时间（6 档：刚刚 / N 分钟前 / N 小时前 / 昨天 / N 天前 / 日期）**。[PRD F-06]

**[AC-20][P0][默认态] running 会话显示**
→ running 会话显示运行图标（如 `⟳ 运行中`）取代时间文本；任务结束转 idle 后图标**自动变回**相对时间（WS 实时同步）。
- ✅ 新行为：人类可读相对时间 / running 图标。
- ❌ 旧行为消失：旧 `toLocaleString()` 原始时间戳展示 → 消失。[PRD F-06 / F-15]

### 原话④-5 — 会话行 hover 操作组

**[AC-21][P0][默认态] hover 出现操作图标**
→ 悬浮会话行 → 右侧出现 **3 个图标**：`⋯ 更多` / `📦 归档` / `📌 置顶 ⇄ 取消置顶`；非 hover 时该区域隐藏，仅显示时间。[PRD F-07]

**[AC-22][P0][功能] 「⋯ 更多」下拉**
→ 含 **4 项**：打开文件夹 / 重命名 / 分享任务·会话 / 删除任务·会话，全部可点且有反馈。[PRD F-07]

**[AC-23][P0][默认态 / 互斥性] 「分享」为禁用态**
→ 「分享」项 **disabled + tooltip「即将上线」**，点击无效果、不跳转、不产生任何 URL / 链接。
- ✅ 新行为：disabled 态、无死链。
- ❌ 旧行为消失：旧 `ShareDialog.vue` 一打开就 `watch(props.show)` 自动 `generateUrl()` 产出 `/#/share/...` 404 死链（路由无 `/share/`）→ **连同该 watch 一并移除**（F1b）。[PRD §10.2 / §10.5-A / U5]

**[AC-24][P1][功能] 「打开文件夹」**
→ = `openPath(workspace)`；工作目录为空时该项置灰。[PRD F-13]

**[AC-25][P0][持久化 / 互斥性] 归档图标**
→ 点击归档 → 该会话从**左栏所有分组消失**（软隐藏）；若归档的是当前 active 会话 → 自动切到 Recent 首条；数据保留可恢复。
- ✅ 新行为：归档后全局消失、刷新保持。
- ❌ 旧行为消失：旧列表**不过滤 archived** → 归档会话仍显示（F30，与 C-2 孪生）→ 消失。[PRD B-03 / F30]

**[AC-26][P0][持久化 / 互斥性] 置顶 ⇄ 取消置顶**
→ 点击 → 会话在置顶组出现 / 移除；**刷新后保持**（读 `session.pinned`，非本地 Set）。
- ✅ 新行为：置顶持久化、跨刷新保持。
- ❌ 旧行为消失：旧读本地 `Set pinnedSessions` 分组、刷新即丢，且 `continue` 把置顶会话从 `byWorkspace` 排除（§10.5-C）→ 消失；新实现读 `session.pinned` 且非互斥。[PRD B-02 / §10.5-C]

### 原话④-6 — 点击打开会话 + 历史 + 续用最新配置

**[AC-27][P0][功能] 点击会话**
→ 主体栏渲染该会话历史消息。[PRD F-08]

**[AC-28][P0][功能 / 互斥性] 续用最新配置（B-01）**
→ 打开旧会话 → 输入区配置条回显该会话 **5 项配置**（工作目录 / 运行权限模式 / Agent 角色 / 模型 / 技能）；发送消息实际使用回显配置而非全局默认。
- ✅ 新行为：`skills` / `mcpServers` 从 kmaster.db 回读并回显（B-01）。
- ❌ 旧行为消失：旧「仅创建时下发、不落库不回读」→ 打开旧会话配置丢失 → 消失。[PRD B-01 / F-08 / US-5]

**[AC-29][P1][持久化] 重命名**
→ 行名更新；刷新后保持。[PRD F-07 + 后端 rename 端点（已存在）]

**[AC-30][P0][互斥性] 分组非互斥**
→ 一个会话可**同时出现在** Recent、置顶、所属工作目录三组；页面无重复 DOM 行（渲染 key = `${groupKey}:${id}`）。
- ✅ 新行为：非互斥、跨组可见。
- ❌ 旧行为消失：旧互斥分组（`continue` 排除）→ 置顶会话从工作目录组消失 → 消失。[PRD §7-Q8 / §10.5-C]

### 原话④-7 — 定时任务 (总数) 可折叠父节点 + 运行实例

**[AC-31][P0][默认态] 定时任务 (N) 父节点**

## 4. 明确不在验收范围（不验什么）

- **分享真实后端（U5 / F1b disabled）**：不验分享链接可用、不验过期选项（1h / 24h / 7d / 永久）；本期分享入口为 disabled 态。
- **桌面端 `openPath` 真实打开系统管理器**：仅验 entry 置灰 / 可用性判断（Web 下置灰），真实打开依赖桌面环境。
- **跨仓 hermes 改动（S2 否决）**：不要求 hermes 改写 run 文件格式。
- **历史 run 的 耗时 / duration、exit_code 补全**：缺源，允许「—」，非缺陷（§10.1）。
- **真实公网分享 / 鉴权 / 隐私合规**：单开需求，不在本期。
